개인정보처리방침

MEL DISTRIBUTOR · 최종 수정일 2026-08-19

MEL DISTRIBUTOR(이하 "본 도구")는 이용자 본인의 컴퓨터에서만 실행되는 개인용 데스크톱 프로그램입니다. 이용자가 직접 제작한 영상을 이용자 본인이 소유한 소셜 미디어 계정에 게시하는 것이 유일한 목적입니다.

1. 운영 주체

본 도구는 개인이 본인의 콘텐츠 게시 용도로 제작·사용합니다. 일반에 배포하거나 제3자에게 서비스로 제공하지 않습니다.

2. 수집하는 정보

본 도구는 서버를 운영하지 않으며, 개발자에게 어떠한 정보도 전송되지 않습니다. 다음 정보가 이용자 본인의 컴퓨터에만 저장됩니다.

  • 각 플랫폼이 발급한 액세스 토큰 및 리프레시 토큰
  • 연결된 계정의 공개 식별자(사용자명, 계정 ID, 페이지 ID)
  • 이용자가 직접 입력한 제목·설명·해시태그
  • 업로드 실행 기록(시각, 파일명, 성공/실패 여부)

3. 정보의 이용

저장된 토큰은 오직 이용자가 직접 실행한 업로드 요청을 각 플랫폼의 공식 API로 전달하는 데에만 사용됩니다. 다른 용도로 사용하지 않습니다.

4. 제3자 제공

수집한 정보를 제3자에게 판매·대여·공유하지 않습니다. 통신은 이용자의 컴퓨터와 각 플랫폼의 공식 API 서버 사이에서만 직접 이루어집니다.

5. 저장 및 보관

모든 데이터는 이용자 컴퓨터의 프로그램 폴더 내에 저장됩니다. 프로그램 폴더를 삭제하면 저장된 모든 정보가 함께 삭제됩니다.

영상 파일은 일부 플랫폼(Instagram·Facebook·Threads)이 공개 URL을 요구하기 때문에 이용자 본인이 설정한 이용자 소유의 저장소에 일시적으로 업로드되며, 게시가 완료되면 자동으로 삭제됩니다.

6. 연결 해제 및 삭제

이용자는 언제든지 다음 방법으로 연결을 해제하고 데이터를 삭제할 수 있습니다.

  • 프로그램 폴더 내 profiles/ 하위의 해당 폴더를 삭제
  • 각 플랫폼의 계정 설정에서 연결된 앱의 권한을 취소

7. 아동의 개인정보

본 도구는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 수집하지 않습니다.

8. 변경 고지

본 방침이 변경되는 경우 이 페이지에 수정된 내용과 최종 수정일을 게시합니다.

9. 문의

본 방침에 관한 문의는 이 저장소의 GitHub Issues를 통해 접수합니다.

Privacy Policy (English)

MEL DISTRIBUTOR · Last updated 2026-08-19

MEL DISTRIBUTOR ("the Tool") is a personal desktop application that runs entirely on the user's own computer. Its sole purpose is to publish videos created by the user to social media accounts owned by that same user.

1. Operator

The Tool is built and used by an individual for publishing their own content. It is not distributed publicly and is not offered as a service to third parties.

2. Information Collected

The Tool operates no server, and no information is transmitted to the developer. The following is stored only on the user's own computer:

  • Access and refresh tokens issued by each platform
  • Public identifiers of connected accounts (username, account ID, page ID)
  • Titles, descriptions and hashtags entered by the user
  • Upload history (timestamp, file name, success/failure)

3. Use of Information

Stored tokens are used solely to pass user-initiated upload requests to each platform's official API. They are not used for any other purpose.

4. Sharing

No information is sold, rented, or shared with third parties. All communication occurs directly between the user's computer and each platform's official API servers.

5. Storage and Retention

All data is stored inside the application folder on the user's computer. Deleting that folder deletes all stored information.

Because some platforms (Instagram, Facebook, Threads) require a publicly reachable URL, video files are temporarily uploaded to a storage bucket configured and owned by the user, and are deleted automatically once publishing completes.

6. Revocation and Deletion

Users may disconnect and delete data at any time by deleting the relevant folder under profiles/, or by revoking the app's permission in the account settings of each platform.

7. Children's Privacy

The Tool is not directed to children and does not knowingly collect their information.

8. Changes

Any change to this policy will be posted on this page along with a revised date.

9. Contact

Questions about this policy may be raised through this repository's GitHub Issues.
